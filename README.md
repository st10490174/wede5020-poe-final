# Khwezi Bakes Website 

Welcome to **Khwezi Bakes** . This project serves as the foundational design system, structural content map, and asset documentation for the Khwezi Bakes web platform. 

Khwezi Bakes is a luxury patisserie and bespoke cake studio located in Durban, South Africa, blending classical French pastry artistry with vibrant, locally sourced flavours.

## 🎨 Design System & Styling Specs

### Color Palette
The palette was established using Adobe Color tools to ensure proper WCAG accessibility contrast ratios (Adobe, 2026).

| Swatch | Color Name | Hex Code | Role / Usage |
| :--- | :--- | :--- | :--- |
| 🧈 | **Warm Cream** | `#FAF0E6` | **Primary Background** — Creates an inviting, artisanal aesthetic. |
| 🍫 | **Earthy Chocolate** | `#3E2723` | **Primary Text & Headers** — Strong, readable contrast grounding the design. |
| 🌸 | **Soft Terracotta** | `#D87093` | **Key Accent** — Highlights special cake highlights and order buttons. |
| 🌾 | **Golden Wheat** | `#DAA520` | **Secondary Accent** — Used for badges, reviews, and star ratings. |
| 🩶 | **Soft Ash Gray** | `#E0E0E0` | **Border/Divider Neutral** — Provides subtle section separation. |

### Typography
* **Headings & Branding:** `'Cormorant Garamond'`, serif.
* **Body Text & Buttons:** `'Plus Jakarta Sans'`, sans-serif.

> *Note: External CSS stylesheet linking (`styles.css`) and web font imports (via Google Fonts API) will be integrated in the upcoming styling milestone.*

## 📝 Changelog

All notable changes to this project will be documented in this section.



#### 📁 Added
- Created dedicated `/css` directory for external stylesheet storage and clean presentation logic separation.
- Created and linked a new master CSS file across all HTML pages on the website.
- Imported external typography fonts from Google Fonts (`Cormorant Garamond` and `Plus Jakarta Sans`).
- Created dedicated `/js` directory for script modularity and client-side functionality.

#### 🔧 Fixed
- Corrected invalid navigation semantic markup, converting malformed list navigation elements into valid HTML `<nav>` and `<ul>`/`<li>` menu structures.
- Code attributed the contact.html file, added source of code (Gemini AI)
- CSS comments, categorized them according to each section 

#### 🎨 Changed
- Established core base styles, universal CSS resets, and global design tokens.
- Defined custom layout structures using modern CSS Grid and Flexbox modules.
- Applied visual styles, color palettes, and polished UI component styling.
- Refactored media presentation across project pages to use native HTML `<img>` elements for consistent image rendering, alt-text accessibility, and semantic accuracy.

#### 🧪 Tested
- Performed cross-device testing to ensure responsive layout behavior across desktop and mobile viewports.

Based on the feedback received for Part 2 , the following structural and layout corrections were implemented:

* **Mobile Responsive Navigation:** Redesigned the navigation bar using CSS media queries and a hamburger menu toggle for mobile viewports.
* **Flexible Grid Layouts:** Converted fixed-width container layouts and product cards on `index.html` and `menu.html` into fluid CSS Grid and Flexbox layouts.
* **Touch-Friendly UI & Spacing:** Adjusted touch targets, button paddings, and font scaling across small screens to ensure full usability on mobile devices.
* **Footer Layout:** Updated footer column structure from 3 columns to a single centered stack on mobile viewports.

Part 3 Enhancements

### A. JavaScript Functionality & Interaction
* **Interactive Menu Filtering:** Implemented JavaScript logic (`data-category` attribute filtering) on `menu.html` allowing users to filter products dynamically across categories (e.g., Bread, Pastries, Cakes).
* **DOM Manipulation:** Added active state classes and smooth transition animations during menu filtering.

### B. Search Engine Optimization (SEO)
* **On-Page SEO:** Added descriptive `<title>` tags, standard `<meta name="description">` tags, and Open Graph (`og:title`, `og:description`, `og:image`) tags across all HTML pages.
* **Off-Page SEO:** Integrated styled social media icons linking to official profiles on Instagram, Facebook, and TikTok.
* **Technical SEO:** Created root-level `robots.txt` and `sitemap.xml` files to guide search engine crawlers.
